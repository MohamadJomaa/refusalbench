# Data

Put your team's data here: seed inputs, a benchmark subset, scripted
examples for evaluation, whatever your chosen baseline or extension
actually needs.

Rules, no exceptions:

- No personal data. No client data. No real users' information, ever.
- Public datasets, synthesized examples, or data your team generates
  itself.
- Everything in this folder except this file is gitignored by default,
  so committing something here takes a deliberate `git add -f`. If you do
  commit source data, keep it small and confirm again that it contains
  nothing personal.
